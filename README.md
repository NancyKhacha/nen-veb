# Веб-версия НЭН для проверки на людях

Голые экраны из Фигмы (файл `mi1bs4SEhul6N3pfD8msJ7`, страницы 32–36), собранные в работающее
приложение для телефона. Человек ставит его на экран телефона и пользуется неделю: записи
хранятся у него в браузере, на сервер ничего не уходит. Это не код приложения в RuStore:
приложение Марии (`app/`) не трогаем, здесь — отдельная пробная сборка.

## Как открыть

Сборка не нужна — это обычные файлы.

```bash
python3 -m http.server 8787 --directory veb
```

Дальше — http://localhost:8787 в браузере (на компьютере — колонкой шириной с телефон).

**Для участников — https://nancykhacha.github.io/nen-veb/** (GitHub Pages, открытый
репозиторий `NancyKhacha/nen-veb`, только для выкладки; поисковикам сайт закрыт).
Обновить сайт после правок:

```bash
scripts/deploy-veb.sh
```

Скрипт кладёт содержимое `veb/` в `NancyKhacha/nen-veb`, сайт обновляется через минуту-две.
У тех, кто уже открывал приложение, новая версия покажется со второго открытия: первое
берёт файлы из кэша для работы без сети.

## Как устроено

- `index.html`, `css/app.css` — страница и оформление: цвета, шрифт Onest и детали —
  как в голых экранах Фигмы.
- `vendor/preact-htm.js` — Preact + htm одним файлом (13 КБ), без сборки.
- `js/app.js` — каркас: какой экран показать, полоса записи, меню, листы, сообщения.
- `js/store.js` — всё хранится на телефоне (localStorage, фото — IndexedDB).
- `js/records.js`, `js/strip.js` — записи: полоса над меню, плашки идущего сна
  и кормления, листы «Кормление», «Поправить», «Другая запись».
- `js/onboarding.js` — первый вход (страница 36).
- `js/profile.js` — профиль: дети, темы, кнопки записи, копия записей,
  «Для исследования».
- `js/common.js` — «Сохранённое» и поиск.
- `js/tabs/*.js` — вкладки «Сегодня», «Ребёнок», «Для себя», «Мой НЭН».
- `js/content/*.js` — материалы: статьи НЭН из архива и тексты из `app-content/`.
- `sw.js` — работа без сети: всё, что открывали, берётся из кэша.

```js
  return html`<div class="screen"><${Back} title="Рост" />…</div>`;
}

export const routes = [
  // tab — какая вкладка подсвечена в меню; strip — показать полосу записи;
  // night — с 22 до 7 экран тёмный
  { path: '/rebyonok/rost', view: Growth, tab: '/rebyonok' },
];
// что найдёт поиск
export function searchItems(state) { return [{ title, sub, path, text }]; }
```

Правила:
- Тексты — настоящие, из Фигмы и брифов `docs/razdely/`, голосом редакции НЭН, на «вы».
- Детали — только из `css/app.css` и `js/ui.js`: `.screen`, `.card`, `.card-gray`, `.row`,
  `.feed`, `.pill`, `.btn-primary`, `.sheet`, `.toast`. Новые — по образцу Фигмы
  и только в своём файле.
- Время — `now()` из `store.js`, а не `Date.now()`: так работает режим показа.
- Каждое нажатие по функции — `track('раздел:действие')`, без содержимого.
- Без сети работает всё, кроме погоды и того, что не скачано.

## Как проверять на людях

Проверяем главное для первого этапа: заходит ли человек каждый день и что делает.

**Кого звать.** Пять–восемь человек на каждый этап: ребёнку до трёх месяцев, от трёх месяцев
до года, от года до трёх лет, от трёх до семи; отдельно — ждущие малыша. Телефоны — и Android,
и iPhone. Лучше те, кто сейчас не пользуется приложением НЭН: им первый вход новый.

**Встреча, 30 минут** (по видео или рядом). Человек открывает ссылку на своём телефоне
и вслух говорит, что видит и что думает. Задания — по путям из Фигмы, без подсказок:
1. Поставьте приложение и начните с ним, как будто скачали его сами.
2. Запишите кормление, которое было полчаса назад.
3. Поправьте время последней записи.
4. Посмотрите, сколько ребёнок спал вчера.
5. Найдите, когда следующая прививка.
6. Найдите что-нибудь для себя, когда пять минут свободны.
7. Сохраните статью, чтобы прочитать вечером, и найдите её снова.
Вечер и ночь на встрече показывают через «Профиль → Для исследования → Режим показа».

**Неделя в жизни.** После встречи человек оставляет приложение на экране и пользуется как
хочет. Ничего не напоминаем — проверяем, вернётся ли сам. На седьмой день он открывает
«Профиль → Для исследования», копирует отчёт и присылает, а потом отвечает на пять вопросов:
что открывали чаще всего и зачем; что раздражало; чего не хватило; в какой момент дня
открывали; стали бы пользоваться дальше.

**Что считаем по отчётам.** В сколько из семи дней открывали; вернулись ли на второй день;
сколько записей в день; какие функции нажимали; сколько времени от первого экрана до первой
записи (по встрече).

**Как поставить на экран.** Android, Chrome: меню ⋮ → «Добавить на главный экран».
iPhone, Safari: «Поделиться» → «На экран „Домой“». После этого приложение открывается
отдельным окном и работает без сети.

**Если человек сменил браузер или почистил его — записи пропадут.** Перед неделей
предупредите об этом; копия записей — в профиле.

## Замер

Только обезличенный счёт: дни, когда открывали, часы и нажатия по функциям
(`js/stats.js`). Имён, дат, текстов записей и заметок в отчёте нет. Отчёт человек сам
копирует в «Профиль → Для исследования» и присылает.

## Что в веб-версии не так, как в приложении

- Вход, Клуб, курс и покупки не работают: экраны есть, а данные — показательные.
  В «Для исследования» можно включить «С курсом» и «В Клубе», чтобы показать эти состояния.
- Пушей нет: браузер не напоминает, пока приложение закрыто.
- Копия записей — простой файл без шифрования и кода.
- Записи второго взрослого и семейный доступ не работают.
